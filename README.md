## 数値の扱い

スライド内の数値は一次情報で裏取り済み。ARC-AGI-3の62.7%は標準ハーネス（各社共通条件）、99.9%と操作効率（96.0%/51.7%）はProvider Adapter条件での測定であり、条件が異なる。

**この % は正答率ではない。** ARC-AGI-3 のスコアは RHAE（Relative Human Action Efficiency）で、レベルごとに `(人間の基準手数 ÷ 実手数)²` を採り、未クリアのレベルは 0 点として平均したもの（[定義](https://docs.arcprize.org/methodology)）。したがって `100 − 62.7 = 37.3` は未クリア率ではなく、「約4割は解けていない」とは言えない。両版とも「人間の水準にはまだ届いていない（スコア62.7%）」という表記に統一してある。

**100% も実測された人間のスコアではない。** 「全レベルをクリアし、手数も人間の中央値並み」という基準点であり、[人間側の測定](https://arcprize.org/blog/arc-agi-3-human-dataset)では各環境を最低2名がクリアしている一方、全員が全レベルを解けたわけではない。2枚目の棒グラフの「人間 100%」には基準値である旨を併記してある。

エンジニア版はこの条件差に1枚を割いているため、**99.9%と操作効率は6枚目まで出さない**（役員版は2枚目・3枚目に出している）。また 62.7 → 99.9 は要素を一つずつ変えて測った実験ではないため、因果の主張はしない旨をスライド面と発表者ノートの両方に明記してある（推論量を揃えた比較でも 35.8〜45.1 ポイントの差が残ることは併記）。
