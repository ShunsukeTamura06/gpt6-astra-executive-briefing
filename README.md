# AI能力境界の変化 ― ブリーフィング資料

ARC-AGI-3のスコア推移（2026年3月 ほぼ0% → 9月 62.7%）を題材に、AIの能力境界がどう変わったかを8スライドにまとめた発表資料。`exec_ai_briefing.html` をブラウザで開けばそのまま発表できる（単一HTML・外部リソース参照ゼロ）。`↓`/`PageDown` で送り、`N` キーで発表者ノート表示。`exec_ai_briefing_backup.pdf` は表示が崩れた場合の保険。

スライド内の数値は一次情報で裏取り済み。ARC-AGI-3の62.7%は標準ハーネス、操作効率（96.0%/51.7%）はProvider Adapter条件での測定であり、条件が異なる点に注意。
