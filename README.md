## 参考スライド（本編のあと、時間が余れば）

**10枚目 FL Studio** ― Astra に作曲ソフトを操作させて短い曲を書き出させた自作の記録。スクリーンショットと音声（`assets/evening_window.wav`、32秒）。

- 音声は**自動再生しない**（`<audio controls preload="none">`）。押したときだけ鳴る。投影前に音声の出力先を確認すること。
- 見せどころは曲の出来ではなく、「F9 は知識として知っていた。画面から推測したわけではない。開いた後は実際の画面を確認して操作している」という Astra 自身の説明。
- 4枚目で主張している「何をすべきかを理解して段取りを組む」の中身が、事前知識と画面判断の噛み合わせだと分かる一次資料になっている。

## 数値の扱い

スライド内の数値は一次情報で裏取り済み。ARC-AGI-3の62.7%は標準ハーネス（各社共通条件）、99.9%と操作効率（96.0%/51.7%）はProvider Adapter条件での測定であり、条件が異なる。

エンジニア版はこの条件差に1枚を割いているため、**99.9%と操作効率は5枚目まで出さない**（役員版は2枚目・3枚目に出している）。また 62.7 → 99.9 は要素を一つずつ変えて測った実験ではないため、因果の主張はしない旨をスライド面と発表者ノートの両方に明記してある。

## 検証

レイアウト崩れの確認は、各 `<section>` を単体HTMLに切り出して 1600×900 のヘッドレスChromeでレンダリングして行う（`tools/render_screenshots.mjs` は macOS の Chrome パスと役員版を決め打ちしているので、環境に合わせて調整が必要）。
